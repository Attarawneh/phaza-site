How the series works

What a number on a Phaza note means

01

Numbered, not dated only

Notes are PTN-01, PTN-02 and so on, in order of first publication. A number is never reused and never retired.

02

Versioned in place

A note keeps its URL across versions. Substantive changes raise the version number and are listed in the note's own changelog.

03

Superseded, not deleted

Earlier versions stay reachable at a versioned address, so a citation made last year still resolves to the text that was cited.

04

Method before findings

A note states how a thing was measured before it states what was measured. Results without a published protocol are not released as notes.

Citations take the form: Phaza (year). Title. Phaza Technical Note NN, version N.N, with the note's URL. Correspondence on any note goes to support@phaza.io.
